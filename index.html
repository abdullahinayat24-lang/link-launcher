☁️ AES-256 Cloud Sync (GitHub Gist)

Synchronize your encrypted bookmarks and profile mappings across multiple PCs using a private GitHub Gist.

📖 30-Second Setup Guide
1. Get GitHub Token: Click Get Token (1-Click) ↗, keep gist checked, click Generate token at the bottom, and paste your GitHub personal access token below.
2. Get or Auto-Create Gist: If you don't have a Gist ID, simply click ✨ Auto-Create Gist or open gist.github.com ↗ and copy the ID from your URL bar.
3. Sync Across Devices: Click ⬆ Push to Cloud on your primary PC. On any other PC or incognito browser, enter the same Token & Gist ID and click ⬇ Pull from Cloud to restore all your links!
